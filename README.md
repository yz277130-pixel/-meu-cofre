# Meu Cofre

Aplicativo web instalável (PWA) para registrar depósitos, acompanhar uma meta, pontuação, sequência mensal e conquistas.

## Publicar no GitHub Pages

1. Entre no GitHub e crie um repositório novo, por exemplo `meu-cofre`.
2. Extraia este ZIP no celular ou computador.
3. Envie **todos os arquivos e pastas que estão dentro** da pasta `meu-cofre` para a raiz do repositório. O arquivo `index.html` deve ficar visível na página inicial do repositório.
4. No repositório, abra **Settings > Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`, depois toque em **Save**.
7. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.

## Instalar no Android

1. Abra o endereço publicado no Chrome.
2. Abra o menu de três pontinhos.
3. Toque em **Instalar app** ou **Adicionar à tela inicial**.
4. Confirme. O Meu Cofre aparecerá como aplicativo no celular.

## Recursos

- Meta inicial de R$ 5.000, editável.
- Depósitos de qualquer valor, com atalhos de R$ 10, R$ 20, R$ 30 e R$ 50.
- 1 ponto por real depositado.
- Histórico com opção de excluir lançamentos.
- Conquistas e acompanhamento de sequência mensal.
- Exportação e importação de backup JSON.
- Dados armazenados localmente no navegador/aparelho.

## Importante

O app não acessa sua conta bancária e não transfere dinheiro. Você registra manualmente os valores que realmente guardou. Os dados ficam no armazenamento local do navegador; limpar os dados do navegador ou trocar de aparelho pode apagá-los. Use **Exportar dados** regularmente para manter uma cópia de segurança. O lembrete mensal é exibido dentro do aplicativo; notificações automáticas não estão ativadas nesta versão.
